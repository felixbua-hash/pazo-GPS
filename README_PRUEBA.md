# Pazo Baion GPS — Beta v9.4

Base: Beta v9.3.

## Cambios Beta v9.4

- Se simplifica la pantalla de informe: se eliminan las pestañas Resumen / Trabajo / Eventos / GPS / Viento / Incidencias / Exportar.
- La pantalla muestra un único informe visual estructurado para consulta en el móvil.
- El informe visual integra datos del trabajo, jornada, tiempos, tramos, paradas, GPS/ruta, viento automático, eventos e incidencias.
- Se mantienen acciones específicas en trabajos pendientes: Retomar / continuar y Terminar trabajo.
- Se añade salida final documental mediante dos acciones claras: Compartir / guardar informe e Imprimir / guardar PDF.
- El informe final se genera localmente en formato maquetado para envío por mensajería/email/WhatsApp, guardado en archivos o impresión/PDF según opciones del dispositivo.
- Se conserva lo incorporado en Beta v9.2 y v9.3: viento automático en fitosanitarios y gestión diferenciada de trabajos pendientes.

Entrega:
- ZIP en raíz, sin subcarpetas.
- Sin PARCELAS.geojson ni INCIDENCIAS_.geojson reales.
